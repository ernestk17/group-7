1. Overview of the Website Project

Our website represents six Makerere University students in Group 7. Each student has their own webpage built with their own personal style and hobbies. The pages are united into one website through a shared top navigation bar and footer buttons.

  • index.html • Nantume Bakhita Grace (Literary journal theme, novel reading)
  • daniella.html • Kagoda Daniella Evelyn (Purple aesthetic theme, reading)
  • ernest.html • Kayondo Ernest (Dark tech theme, aspiring DevOps engineer)
  • ntwari.html • Ntwari Joseph David (Green sports theme, football)
  • ibrahim.html • Lubega Ibrahim (Classic green & gold theme, golf & football)
  • matthew.html • Musiinguzi Matthew Jekyns (Dark contrast theme, basketball & chess)

Key Design Decisions Made:

  • No Emojis: All icons are standard vector icons loaded via the industry-standard Font Awesome CDN.
  • No Artificial Highlight Strips: All cards have clean, uniform, balanced borders all around.
  • Individual Stylesheets: Each student has their own CSS file (e.g. css/ernest.css), proving separate work.

3. How the CSS Works (css/ernest.css)

1. Reset and Theme Colors

* {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}
body {
  background-color: #0f172a;
  color: #e2e8f0;
  font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;
  line-height: 1.6;
}
  • box-sizing: border-box: Makes sure padding and borders don't increase the total width of elements, preventing horizontal overflow.
  • #0f172a: Dark slate background fitting a tech and cloud developer portfolio.

2. Clean, Balanced Cards

.card {
  background: #1e293b;
  border: 1px solid #334155;
  border-radius: 8px;
  padding: 1.5rem;
  margin-bottom: 1.5rem;
}
  • Clean 1px border all around. No one-sided highlight stripes, giving it a clean, human design.

3. Responsive CSS Grid for Hobbies

.hobbies-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(180px, 1fr));
  gap: 1rem;
}
  • repeat(auto-fit, minmax(180px, 1fr)): Automatically fits as many 180px cards across the screen as possible, wrapping to the next line on smaller devices without needing complicated media queries!

4. How the JavaScript Works (js/main.js)

The JavaScript is lightweight (under 60 lines) and uses plain vanilla JavaScript.

1. DOMContentLoaded Listener

document.addEventListener('DOMContentLoaded', () => {
  const student = document.body.getAttribute('data-student') || 'student';
  ...
});
  • Waits until all HTML elements are loaded before running the script so it never crashes.
  • Reads data-student="ernest" so Ernest's likes and comments are stored in his own separate storage key.

2. The Like Button Logic

const storageKey = 'group7_likes_' + student;
let count = parseInt(localStorage.getItem(storageKey), 10) || 0;
likeCountSpan.textContent = count;

likeBtn.addEventListener('click', () => {
  count++;
  likeCountSpan.textContent = count;
  localStorage.setItem(storageKey, count);
});
  • localStorage.getItem(storageKey): Retrieves saved likes from the browser.
  • count++: Increments the like counter by 1 on every click.
  • localStorage.setItem(storageKey, count): Saves the new number so it persists even when the user refreshes or closes the tab.

3. The Comment Submission Logic

commentForm.addEventListener('submit', (event) => {
  event.preventDefault(); // Stops the page from refreshing

  const name = authorInput.value.trim();
  const text = messageInput.value.trim();

  if (name !== '' && text !== '') {
    displayComment(name, text); // Adds the comment to the page
    saved.push({ name, text });
    localStorage.setItem(commentsKey, JSON.stringify(saved));
    authorInput.value = '';
    messageInput.value = '';
  }
});
  • event.preventDefault(): Prevents the default browser action of reloading the page upon form submit.
  • Creates a new <div class="comment-item"> element and appends it to #comments-list.
  • Saves the list of comments as a JSON array in localStorage.
