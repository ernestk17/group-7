How to explain this to the lecturer:

  • <!DOCTYPE html>: Tells the browser to render the page using the latest HTML5 standard.
  • <meta charset="UTF-8">: Sets standard character encoding for text.
  • <meta name="viewport" ...>: Ensures the webpage adjusts nicely on mobile phones and tablets.
  • <link rel="stylesheet" ... font-awesome ...>: Connects the external Font Awesome library so we can display clean icons (like the swimming, running, and gym icons) instead of emojis.
  • <link rel="stylesheet" href="css/ernest.css">: Links Ernest's personal stylesheet with the Instagram UI theme.

3. How the JavaScript Works (js/main.js)

The JavaScript is lightweight (under 60 lines) and uses plain vanilla JavaScript.

1. DOMContentLoaded Listener

document.addEventListener('DOMContentLoaded', () => {
  const student = document.body.getAttribute('data-student') || 'student';
  ...
});
  • Waits until all HTML elements are loaded before running the script so it never crashes.
  • Reads data-student="ernest" so Ernest's likes and comments are stored in his own separate storage key.

2. The Like Button Logic

const storageKey = 'group7_likes_' + student;
let count = parseInt(localStorage.getItem(storageKey), 10) || 0;
likeCountSpan.textContent = count;

likeBtn.addEventListener('click', () => {
  count++;
  likeCountSpan.textContent = count;
  localStorage.setItem(storageKey, count);
});
  • localStorage.getItem(storageKey): Retrieves saved likes from the browser.
  • count++: Increments the like counter by 1 on every click.
  • localStorage.setItem(storageKey, count): Saves the new number so it persists even when the user refreshes or closes the tab.

3. The Comment Submission Logic

commentForm.addEventListener('submit', (event) => {
  event.preventDefault(); // Stops the page from refreshing

  const name = authorInput.value.trim();
  const text = messageInput.value.trim();

  if (name !== '' && text !== '') {
    displayComment(name, text); // Adds the comment to the page
    saved.push({ name, text });
    localStorage.setItem(commentsKey, JSON.stringify(saved));
    authorInput.value = '';
    messageInput.value = '';
  }
});
  • event.preventDefault(): Prevents the default browser action of reloading the page upon form submit.
  • Creates a new <div class="comment-item"> element and appends it to #comments-list.
  • Saves the list of comments as a JSON array in localStorage.
